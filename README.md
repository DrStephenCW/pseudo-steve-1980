# Pseudo-Steve (1980)

Pseudo-Steve was a question-answering program that Stephen Willson (now
Stephen Clarke-Willson) wrote in MLISP on the UC Irvine DECsystem-10 for
ICS 199 in Spring 1980, a research course with Richard Granger.

Steve was the TA for ICS 145, the compiler construction lab, and Pseudo-Steve
answered the routine questions for him: due dates, office hours, what each
assignment is. It followed keywords down a hand-built knowledge tree and
reused the last question's path as context.

`original/` holds the files exactly as recovered from a 1980 TOPS-10 BACKUP
tape. See the next commit for a guide and a working port.

This recovery project was done with Claude Opus 5.5 Medium Effort guided by
Stephen Clarke-Willson.
