Pseudo-Steve

A 1980 MLISP program by Steve Willson, the TA for ICS 145 (compiler construction) at UC Irvine. It answered the routine questions about the course so the real Steve didn't have to.

Try: when is the compiler due, then how about assignment two. Type help for help and thank you when you're done.
